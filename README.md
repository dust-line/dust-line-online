# Пыльный рубеж онлайн — версия 2

Сетевой шутер в браузере. Сервер на Node.js ведёт матчи: считает урон, деньги, раунды и бомбу.
Игроки открывают адрес сервера в браузере (на компьютере или телефоне) и играют вместе.

## Что есть в игре

- **Режимы:**
  - **Обычный (бомба):** спецназ против террористов, до 5 на 5, матч до 7 побед. Деньги и магазин как в одиночной версии: $800 в начале, награда за убийства, раунды и закладку бомбы.
  - **Зачистка:** бомба уже заложена на случайной точке. Террористы появляются рядом и охраняют её, спецназ должен обезвредить её за 40 секунд. Магазин бесплатный, но работает только в начале раунда. Матч до 7 побед.
  - **Бой насмерть:** до 12 игроков, возрождение через 3 секунды, магазин бесплатный и открыт всегда.
- **Карты:** Порт, Зимовье, Завод, Ночной город (все режимы) и Пыльный рубеж (только бой насмерть).
- **Оружие (14 видов):** пистолет, автопистолет, револьвер, ПП, дробовик, автодробовик, лёгкая снайперка, АК-47, М4, винтовка с оптикой, снайперка, пулемёт, гранатомёт и нож. Работает прострел: снайперка пробивает 5 человек, пулемёт 3, автоматы и лёгкая снайперка 2.
- **Снаряжение:** бронежилет, сапёрный набор, осколочная, дымовая и световая гранаты.
- **Скины** на всё оружие и ножи. Их видишь только ты.
- Таблица счёта, радар, лента убийств, наблюдение за союзниками после смерти.

Режим и карту выбирает тот, кто первым зашёл в комнату. Все, кто введёт то же название комнаты, попадут к нему.

## Управление

`WASD` — ходить, мышь — целиться, `ЛКМ` — стрелять, `ПКМ` — прицел или сильный удар ножом, `R` — перезарядка,
`1` основное, `2` пистолет, `3` нож, колёсико — смена оружия, `B` — магазин, `G` / `C` / `F` — осколочная, дымовая, световая граната,
`E` (держать) — заложить или обезвредить бомбу, `V` — осмотр оружия, `Tab` — таблица счёта, `Esc` — меню.
На телефоне — джойстик слева, свайп справа и кнопки на экране.

## Что внутри

```
server.js              сервер: раздаёт игру и ведёт матчи
shared/game-data.js    карты, оружие и правила, общие для сервера и браузера
public/index.html      сама игра
package.json           зависимости (нужна только библиотека ws)
```

## Запуск на своём компьютере

1. Установи Node.js версии 18 или новее: https://nodejs.org
2. Распакуй архив, открой терминал в папке `dust-line-online` и выполни:
   ```
   npm install
   npm start
   ```
3. Открой в браузере http://localhost:3000

Друзья в той же Wi-Fi сети заходят по адресу твоего компьютера, например `http://192.168.1.25:3000`
(адрес можно узнать командой `ipconfig` в Windows, строка IPv4). Если не подключаются — разреши Node.js доступ в брандмауэре.

## Размещение в интернете

Подойдёт любой хостинг, который запускает Node.js и поддерживает WebSocket.

- **Render, Railway и похожие.** Загрузи файлы проекта в репозиторий на GitHub, создай на сервисе
  веб-приложение (Web Service) из этого репозитория. Команда сборки — `npm install`, команда запуска — `npm start`.
  Порт сервис передаст сам. На бесплатных тарифах сервер может «засыпать» без игроков — первый вход тогда займёт до минуты.
- **Свой сервер (VPS).** Скопируй папку, выполни `npm install` и `npm start`. Чтобы сервер работал постоянно:
  `npx pm2 start server.js --name dust-line`.

Адрес `/healthz` отвечает `ok` — его можно указать сервису для проверки.

## Настройки

Правила (деньги, время раунда, число побед), урон и цены оружия лежат в начале `shared/game-data.js`
(объекты `C`, `WEAPONS`, `GEAR`). После изменения перезапусти сервер.

Урон считает сервер и проверяет, что выстрел не идёт сквозь стены, но защиты от читов уровня больших онлайн-игр здесь нет — это игра для друзей.
